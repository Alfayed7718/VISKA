# Aset profil Viska

Masukkan aset JPG Anda ke folder berikut. Nama file ini sudah dipakai langsung oleh halaman profil.

## Avatar

- `avatars/wayang.jpg` — avatar bawaan.
- `avatars/batik.jpg` — Avatar Batik.
- `avatars/royal.jpg` — Avatar Keraton.

## Border

- `borders/soga.jpg` — border bawaan.
- `borders/emas.jpg` — Border Emas.
- `borders/jade.jpg` — Border Giok.

## Gelar

- `titles/prajurit.jpg`
- `titles/pati.jpg`
- `titles/raja-jawa.jpg`

Gunakan gambar persegi untuk avatar. Untuk border, gunakan gambar persegi dengan bagian tengah transparan atau polos agar foto tetap terlihat. Gambar gelar telah disiapkan tempatnya untuk dipakai pada pengembangan desain badge berikutnya.
